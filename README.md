# recommendation-algorithm

# Build Instructions

## Requirements
- CMake 3.10+
- C++17 compiler:
  - Linux: g++, clang++
  - Windows: MinGW-w64 (MSYS2) or Visual Studio Build Tools
  - macOS: Xcode Command Line Tools

## Build
```bash
git clone <repo>
cd recommendation-algorithm
mkdir build
cd build
cmake ..
cmake --build .
